Put licensed character artwork here (PNG/SVG/WebP) and point NEXT_PUBLIC_MASCOT_IMAGE at it,
for example NEXT_PUBLIC_MASCOT_IMAGE=/characters/mascot.png, then rebuild the web app.
A whole set can live in a sub-folder (e.g. /characters/kuromi with scene, logo, mini, cover, cheer, melody, cinna, purin .png)
and be switched on with CHARACTER_PACK=/characters/kuromi in .env; sub-folders are git-ignored and stay on this machine.
Only use images you have the rights to use (e.g. a Sanrio licence). Leave empty to use the built-in "Puni" mascot.
